# Agentic Skills

Systematic evaluation of role-specific agent skills written in `SKILLS.md` format.

The project compares Product Owner, Engineer, and QA skill variants across controlled repo and brief combinations. Each evaluation changes only one skill variable at a time and records objective artifacts, verification results, scores, and failure modes.

## Operating Principle

Evaluate one candidate source through one complete cycle before moving to the next candidate.

```text
one candidate source -> one role -> one skill file -> one brief -> one scorecard
```

## Key Files

- `docs/skill_evaluation_plan.md`: evaluation methodology.
- `docs/progress_tracker.md`: project state and candidate queue.
- `docs/full_cycle_execution_protocol.md`: step-by-step run protocol.
- `rubrics/production_grade_scorecard.md`: scoring rubric.
- `templates/run_metadata_template.yaml`: per-run metadata template.
- `templates/scorecard_template.md`: per-run scorecard template.
